E-Pharmacy — це сучасна веб-платформа для пошуку та замовлення лікарських засобів в онлайн-аптеках. Проєкт складається з клієнтської частини для користувачів та серверної частини для обробки даних, замовлень та авторизації.

Основна мета
Розробка функціонального та інтуїтивно зрозумілого інтерфейсу для взаємодії користувача з асортиментом аптек, керування кошиком та оформлення замовлень.

Основні технології
Frontend: React (TypeScript) / Next.js, Redux Toolkit, React Router / Next App Router.

Backend: Node.js (Express.js), MongoDB (Mongoose).

Стилізація та UI: CSS Modules / Tailwind CSS, UI-бібліотеки (Blueprint, MUI).

Валідація: Formik, Yup.

Візуалізація: Recharts (для статистики).
